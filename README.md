# 営業先リストメーカー（GitHub Pages向け・無料試作版）

地域・半径（最大5km）・業種を指定して、OpenStreetMap/Overpass API に登録された店舗候補を取得し、公式サイトURL・お問い合わせURL（手動入力）・営業状況を管理してCSV出力する静的Webアプリです。

## できること
- 地図クリックまたは地名検索で中心地点を指定
- 半径1〜5kmで検索
- 飲食、美容、整体・施術系、その他店舗で絞り込み
- 店名・住所・登録されている公式サイト・電話番号を表示
- お問い合わせページURL・対応状況・メモを手動で保存
- CSV出力（Excel向けUTF-8 BOM付き）
- 営業データは利用中ブラウザの localStorage に保存

## GitHub Pagesへの追加手順
既存の営業サイトに影響を与えないよう、**別のリポジトリ**に置くことをおすすめします。

1. GitHubで `lead-finder` などの新しいリポジトリを作る（Public）。
2. このフォルダの `index.html` と `README.md` をリポジトリのルートにアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment** で `Deploy from a branch` を選び、branch を `main`、folder を `/(root)` にして Save。
5. 数分待って、Pagesに表示されたURLを開く。

独自ドメイン、サーバー、APIキーは不要です。外部ライブラリ（Leaflet）はCDNから読み込みます。

## 使い方
1. 地図をクリックして中心地点を選ぶか、住所・地名を入力して「検索」を押します。
2. 半径と業種を選択します。
3. 「この範囲のお店を検索」を押します。
4. 問い合わせページが見つかったら、URL欄に手動入力してフォーカスを外します。
5. 対応状況・メモを更新するとブラウザに保存されます。
6. 「CSV出力」で表計算ソフトに保存します。

## 重要な制約・利用上の注意
- OpenStreetMapの登録情報を使うため、候補の網羅性や正確性は保証されません。住所、業種、公式サイトが未登録の店舗は検索結果に出ないことがあります。
- 問い合わせページURLは自動でクロール・推測しません。公式サイトを人が確認して登録してください。
- 公開Overpass APIは共有サービスです。検索ボタンを押した時だけリクエストを送り、連続検索や大量利用を避けてください。混雑時に失敗することがあります。長期的・大量の商用利用には、適切なホスティング先やデータ提供元を検討してください。
- 地名検索にはNominatimを使います。自動補完やバックグラウンド連続検索は行わず、ユーザーが検索ボタンを押したときだけ問い合わせます。[Nominatim利用ポリシー](https://operations.osmfoundation.org/policies/nominatim/)を必ず確認してください。公開サービスには厳しい制限があり、広範囲の体系的なデータ収集や大量利用には向きません。
- 地図とデータの帰属表示を削除しないでください。[地図タイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)とOpenStreetMapデータのライセンス・帰属条件を確認してください。
- 営業連絡の前に、店舗の公式情報と問い合わせフォームの利用条件を確認してください。大量送信・無差別な自動送信はしないでください。
- `localStorage` は同じブラウザ・端末内だけに保存され、GitHubや他の端末に同期されません。ブラウザデータ削除で消える場合があるので、定期的にCSVでバックアップしてください。
- この試作版は検索結果をすべて蓄積する設計です。業務で使う場合は、古い情報の更新や重複整理を行ってください。

## 技術
- HTML / CSS / JavaScript
- Leaflet + OpenStreetMap tiles
- Nominatim geocoding (user-triggered)
- Overpass API (user-triggered)
- localStorage / CSV export

## 既知の制約
- 公式サイトや問い合わせURLの自動検出・検証はしません。
- 公開APIの混雑やCORS、利用制限によって検索できない場合があります。
- 検索カテゴリはOpenStreetMapのタグ付けに依存し、整体院などが医療系タグに登録されていない場合は見つからないことがあります。
- 無料の共有APIに対するサービス保証はありません。
