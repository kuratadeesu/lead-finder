# 営業先リスト管理ツール（改良版）

## できること
- 地図をクリック／ドラッグ、または場所名・住所から検索中心を指定
- 半径1〜5km、業種を選んでOpenStreetMapデータから営業先を検索
- 検索結果は既存リストに追加。既存の手動登録データは検索時に削除されません
- 営業先の手動追加・編集・個別削除
- 状況管理、検索・絞り込み、CSV出力
- ブラウザの localStorage に保存

## GitHub Pagesへの配置
1. ZIPを解凍し、`index.html` と `README.md` を別の新規Publicリポジトリのルートにアップロードします。
2. GitHubリポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、Branch=`main`、Folder=`/(root)` を指定して Save。
4. 公開されたURLを開きます。

既存サイトを変更したくない場合は、別リポジトリにしてください。

## 注意
- 登録データは同じブラウザ・端末内に保存され、別端末とは同期されません。ブラウザデータを消すと失われることがあるため、定期的にCSVを書き出してください。
- 公開API（Nominatim / Overpass）とOpenStreetMapの地図タイルを使用しています。アクセス集中時には検索に失敗することがあります。データの網羅性・正確性は保証されません。
- お問い合わせページURLは手動で入力します。自動巡回はしません。
- OpenStreetMapのデータとタイルには利用ポリシーがあります。過度な連続リクエストを避けてください。
